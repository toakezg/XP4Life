## Setup Rule
Do not redesign the vault around a plugin until the manual markdown flow already feels correct.

## Git Setup Rule
Use [[Git Commit Policy]] before creating the first commit. Workspace state and plugin binaries are intentionally ignored for the first baseline.

## First Validation Pass
1. Open the starter dashboard.
2. Open one active quest.
3. Complete a task manually.
4. Mark the quest complete when ready.
5. Update the linked achievement YAML by hand.
6. Confirm the dashboard still reflects the system cleanly.
