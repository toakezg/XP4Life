# PLAN

## Project Direction
Build XP4Life into a modular progression engine that works cleanly in plain Obsidian and becomes stronger through optional plugin layers.

## Current Phase
Phase 2 - Governance, plugins, maps, and git-prep stabilization

## Phase Outline

### Phase 1
- Build the first playable vault structure
- Create core notes, templates, dashboard, quests, achievements, and titles
- Prove the base loop in markdown and YAML

### Phase 2
- Add root docs and project contract
- Tighten tone, naming, and category consistency
- Keep plugin use optional and additive
- Review quest and achievement quality before deeper automation
- Confirm installed plugins and document enhancement layers
- Create Mermaid maps for roadmap and current state
- Prepare the vault for a clean first git commit

### Phase 3
- Confirm foundation plugins in waves
- Add faster creation and claim flows
- Improve dashboard quality and category progress views
- Stabilize Templater creation workflows after git baseline

### Phase 4
- Add level curve, stronger title progression, and optional quest chains
- Explore automation triggers, visuals, and graph-style progression maps
- Build detailed quest chains only after the base loop has more proof

## Immediate Next Steps
1. Get explicit user approval to stage and commit the first baseline.
2. Run `git status --short --ignored` immediately before staging.
3. Stage and create the first git baseline.
4. After the baseline exists, move into Phase 3 dashboard and creation-flow upgrades.
