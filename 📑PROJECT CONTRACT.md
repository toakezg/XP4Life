# PROJECT CONTRACT

## Purpose
Build XP4Life into a usable Obsidian-native progression system for real-world execution, project tracking, creative output, monetization, and personal growth.

## Success Condition
The vault functions as a clean first-version progression engine with:
- a readable core that works in plain markdown and YAML
- live quest, achievement, title, and dashboard notes
- roadmap and current-state maps for orientation
- clear project docs for direction, tracking, and setup
- a stable base for later plugin enhancements

## Constraints
- Keep the core plugin-light.
- Do not make the vault depend on automation too early.
- Preserve readability and practical use over flashy complexity.
- Use YAML as the state source of truth.
