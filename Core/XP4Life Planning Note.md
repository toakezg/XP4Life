# XP4Life Planning Note

## System Vision
- Build XP4Life as a playable life and project operating system inside Obsidian.
- Make progress feel tangible through quests, achievements, XP, titles, rarity, and visible momentum.
- Keep the tone immersive but grounded so the system stays motivating without turning into fluff.

## Core Loop
Tasks -> Quests -> Achievements -> XP -> Titles -> Progression

- Tasks are the action layer.
- Quests are the mission layer.
- Achievements are the milestone layer.
- XP is the reward currency.
- Titles are identity rewards that mark progression.
- YAML and Dataview act as the state layer.

## Current Folder Structure
- `Core/` for high-level rules, planning, and handoff notes.
- `Systems/` for plugin-aware notes and system logic.
- `🖥 MENU/Quests/Active/` and `🖥 MENU/Quests/Completed/` for the mission layer.
- `🖥 MENU/Achievements/Core/`, `🖥 MENU/Achievements/Unlocked/` for milestone tracking.
- `🖥 MENU/Titles/` for rank and identity rewards.
- `🖥 MENU/Guides/XP/` for XP rules and progression references.
- `🖥 MENU/Dashboard.md` for the live command view.
- `Indexes/` for quest and achievement rollups.
- `🖥 MENU/Guides/` for day-to-day operating notes.
- `Templates/` for global Templater-ready note templates.
- `Assets/` for images, icons, and proof media.
- `MAPS/` for Mermaid orientation maps.

## Starter Content To Generate
- 10 starter quests across build, system, creative, money, and personal tracks.
- 15 starter achievements with global and industry rarity.
- 5 starter titles with clear unlock conditions.
- Core overview, templates, indexes, dashboard, plugin notes, XP rules, and a pass-one handoff note.
