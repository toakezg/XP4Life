# XP4Life Build Notes - Pass 1

## What Was Created
- Core planning, overview, XP rules, plugin notes, and daily-use guidance.
- A folder structure for quests, achievements, titles, dashboard, indexes, and templates.
- 10 starter quests across system, build, creative, money, and personal tracks.
- 15 starter achievements with dual rarity fields and XP bonuses.
- 5 starter titles with clear unlock conditions.
- A starter dashboard and index notes powered by Dataview-friendly YAML.

## Assumptions Made
- `The idea of XP4Life convo` is the primary design brief and source of truth.
- The vault should feel immersive but stay readable and practical.
- Plugin awareness matters, but plugin installation can follow after the base build.
- YAML should hold the progression state even before any automation exists.

## Recommended Next Steps
1. Install or confirm the intended plugin stack, especially Dataview, Tasks, Templater, QuickAdd, MetaEdit, and Buttons.
2. Complete `Forge Foundations` first so the system has a finished quest and first claimed achievement.
3. Decide one real build target for `Reusable Tool Pass` and one real offer for `Signal to Market`.
4. Add a simple daily note workflow once the quest loop feels natural.
5. In pass 2, consider QuickAdd or Buttons commands for claim actions and quest creation.

## Areas To Refine Later
- XP level curve and level names.
- Automatic movement of completed quests.
- Achievement chains and unlock dependencies.
- Optional separation between main quests, side quests, and daily quests.
- Stronger visual styling once plugins and theme decisions are in place.
