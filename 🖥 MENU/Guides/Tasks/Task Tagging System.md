# Task Tagging System

## Purpose
Tags make project tasks filterable without turning `TASKS.md` into a heavy database.

## Core Tags
| Tag | Use |
| --- | --- |
| `#task` | General project task |
| `#git-ready` | Work needed before first commit |
| `#docs` | Documentation task |
| `#cleanup` | File, folder, link, or naming cleanup |
| `#plugin` | Plugin setup or validation |
| `#map` | Mermaid maps and orientation |
| `#scope` | Scope control and later-phase decisions |
| `#manual-check` | Requires Obsidian UI confirmation |
| `#quest-loop` | Quest completion and reward-flow validation |

## Quest Tags
| Tag | Use |
| --- | --- |
| `#quest-task` | Checkbox inside a quest |
| `#build` | Build/development work |
| `#system` | Vault/system work |
| `#creative` | Creative output |
| `#money` | Monetization work |
| `#personal` | Personal growth work |

## Rule
Use one broad status tag and one topic tag when possible. Example: `#task #git-ready`.
