# XP Rules

## XP Sources
- Quest XP comes from `xp_reward` on completed quests.
- Achievement XP comes from `xp_bonus` on unlocked achievements.
- Titles do not grant XP by default. They mark identity and progression.

## Pass 1 Formula
Total XP = sum of completed quest XP + sum of unlocked achievement XP

## Reward Philosophy
- Quests pay for motion.
- Achievements pay for proof.
- Titles pay in identity, not numbers.

## Suggested XP Feel
| Tier | Suggested Quest XP |
| --- | --- |
| Common | 25-75 |
| Uncommon | 100-200 |
| Rare | 250-500 |
| Epic | 600-1200 |
| Legendary | 1500+ |

## Future Expansion
- Add a level curve after a few weeks of real use.
- Add category-specific XP if build, money, creative, and personal tracks need separate momentum.
- Add automation when the manual claim flow feels too slow.
