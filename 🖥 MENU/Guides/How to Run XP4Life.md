# How to Run XP4Life

For the step-by-step operating guide, see [[XP4Life How-To]].
Templates are now centralized in `Templates/` for Templater use.

## Daily Use
1. Open the dashboard.
2. Pick one active main quest and one support quest.
3. Work the next visible checkboxes.
4. Capture any result, artifact, link, or note inside the quest.
5. When the quest is done, complete the quest, claim linked achievements, and review titles.

## Weekly Use
1. Review the Active Quests table.
2. Move any finished quest into `🖥 MENU/Quests/Completed/`.
3. Review unlocked achievements and total XP.
4. Create one new quest to keep the system alive.
5. Adjust tiers or rarity estimates if they feel obviously off after real use.

## Tone Check
- Keep the naming immersive.
- Keep the actions practical.
- If a note stops helping execution, simplify it.
